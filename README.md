# Tugas-1-Proyek-Pemrograman-Web

Saya membuat web profil diri menggunakan HTML Dasar.
Untuk membuat web ini saya menggunakan beberapa kode sederhana diantaranya:
-Saya menggunakan kode '<h1>' untuk heading, untuk membuat judul
-kode '<p>' untuk membuat teks teks
-kode '<a>' untuk membuat tulisan menjadi hyperlink
-kode '<hr>' untuk membuat garis 
-saya juga menambah image dengan kode '<img>' dan video menggunakan kode "<video> <source>"
-agar image dan video menjadi bersebelahan saya membuatnya dalam bentuk table tanpa border dengan kode '<table>' didalam tabel data '<td>' baru saya masukkan kode image dan video
-saya juga membuat tabel untuk riwayat pendidikan kali ini dalam bentuk tabel bergaris menggunakan kode "<table border="1">" lalu terdapat table head baru tabel data "<th> <td>"
-kode "<ul> <ol> <li>" untuk membuat list dalam bentuk nomor dan lingkaran hitam kecil
-kode '<form>' untuk membuat inputan. '<input>' dan '<label>' untuk membuat kotak penginputan dan nama dari kotak input. dan untuk membuat teks di dalam kotak input menggunakan placeholder
-kode '<textarea>' untuk membuat kotak input yang lebih besar diatur menggunakan cols dan rows 
-di kode input terdapat juga type dari input. disini saya menggunakan type teks, email, dan juga submit. type submit berguna untuk button
-terdapat juga kode width dan height untuk mengatur tinggi dan lebar sebuah frame image atau video.
